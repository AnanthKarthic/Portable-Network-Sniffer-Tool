# Portable Network Sniffer Tool

### Objective

I created the Portable Network Sniffer Tool in order to build a tool that explores how devices communicate on a local network while strengthening foundational skills in Python programming, network scanning, and Linux-based tooling.

### Skills Learned

- Python programming for network-related tools
- ARP-based network scanning and device discovery
- Packet analysis using Scapy
- Using Linux command-line tools for networking tasks
- Mapping MAC addresses to device manufacturers
- Data visualization with Matplotlib
- Deploying and testing software on a Raspberry Pi
- Basic hardware integration and enclosure design through 3D designing and printing
  
### Tools Used

- Python (Tkinter, Matplotlib) for application logic, GUI, and visualization
- ARP-Scan and Scapy for local network discovery and packet analysis
- Linux command-line tools on Raspberry Pi 3B for deployment and testing
- 3D modeling and 3D-printed enclosure design (Tinkercad)
